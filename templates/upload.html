About SCD Files

SCD (Substation Configuration Description) files are XML-based files defined by IEC 61850 standard. They contain complete configuration information for substation automation systems including:

  • IED (Intelligent Electronic Device) definitions
  • Logical nodes and data objects
  • Communication parameters
  • GOOSE and SMV message configurations
What You'll Get

After parsing your SCD file, you'll receive:

  • Complete IED inventory with details
  • Communication link analysis
  • Network topology visualization
  • Export options (PNG, SVG, PDF)
  • Statistical summaries
